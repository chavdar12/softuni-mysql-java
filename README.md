# SoftUni MySQL

Solutions for the SoftUni Databases Basics – MySQL course. One `.sql` file per problem; queries start with a `-- database:` line
naming the SoftUni sample database they run against (`soft_uni`, `geography`, `gringotts`, …). CI lints every file with
SQLFluff.
